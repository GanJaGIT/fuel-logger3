# План новой версии FuelLog 4

## Ограничения среды
- ПК под Secret Net, без сети: никаких сетевых зависимостей, СУБД и онлайн-обновлений.
- Установка одним файлом: self-contained .NET 10, установщик Inno Setup (как раньше) или переносная папка.
- Данные хранятся в JSON (требование).

## Стек
- **.NET 10 + WPF** с встроенной темой Fluent (светлая/тёмная/как в системе). Работает без доп. runtime, знаком текущему разработчику.
- **CommunityToolkit.Mvvm**: MVVM без лишнего кода.
- **ClosedXML**: формирование Excel.
- **xUnit**: тесты расчётов, хранения и отчёта.

## Архитектура
```
src/FuelLog.Core   – модель, расчёт, хранение, Excel (без зависимостей от WPF, покрыто тестами)
src/FuelLog.App    – WPF-интерфейс (MVVM)
tests/FuelLog.Tests
installer/         – Inno Setup
```

## Модель данных (один файл проекта `*.gsmproject`, JSON со `schemaVersion`)
- `Catalog`: справочник марок (бак осн./доп., расход на 100 км и в час, топливо, категория).
- `Groups` (воинские части/рп) → `Units` (подразделения) → `Vehicles` (ссылка на марку + количество).
- `Tasks`: название, тип, **дата**, признак «в расчёт», строки техники (подразделение, марка, кол-во, км, ч, % потерь).
- Все связи по `Guid`, без копирования параметров.
- Запись атомарная (временный файл + замена), автоматические резервные копии (последние 10).
- Импорт проектов и шаблонов старой версии.

## Методика расчёта (по образцу)
- Работающие машины: `N − L`, где потери `L = round(N × p%)`.
- Расход, л = `(N − L) × (км/100 × норма_100 + ч × норма_час) + L × (бак осн. + бак доп.)`.
- Расход, кг = л × плотность (АБ/ДТ из настроек).
- Масса заправки уровня = Σ (баки × кол-во × плотность) по **всей** технике подразделения / рп / итога.
- Заправки = кг / масса заправки этого уровня.
- Среднесуточный расход = заправки / число различных дат в группе строк.

## Интерфейс
1. **Структура**: дерево рп → подразделения, состав техники с правкой прямо в таблице, сводка по АБ/ДТ.
2. **Справочник техники**: таблица с поиском и фильтром по категориям, импорт/экспорт.
3. **Задачи**: список задач с датами, редактор состава, копирование задачи, предварительный итог.
4. **Отчёт**: предпросмотр в программе и выгрузка в Excel (лист «Расчёт» по образцу + лист «Детализация» по маркам).
5. **Настройки**: плотности, типы задач, категории техники, тема.

## Этапы
1. Core: модель, расчёт, тесты на числах из образца.
2. Хранение: атомарная запись, резервные копии, миграция старого формата.
3. Excel-отчёт и тесты на него.
4. WPF-интерфейс.
5. Сборка, установщик, руководство пользователя.
